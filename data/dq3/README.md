### `hero-memo.yaml` — ★書くのは 4 つだけ

```text
① 覚えておきたいこと     memo
② いつ気になり始めるか   appears_when
③ いつ気にならなくなるか retires_when   ⚠⚠ 必須（★永久に残るメモは作れません）
④ どこの話か             about          ★補足の場所（⚠ 話・目的は ⑤ へ）
⑤ 何の話として気にしているか scenario   ★任意（2026-09-27 / RX3-0434）
```

⚠ 順番・優先度・段階・親子関係、内部 ID（item_id / map_id / RAM 番地）は
★**書きません**。⚠ 詳しい書き方はファイルの先頭のコメントにあります。

★2026-09-27 に決まったこと（RX3-0434）:

- ★`scenarios:` に `id: {title: …}` を書き、カードに `scenario: <id>` と書くと、画面で束ねて出ます。
  ⚠ 定義に書けるのは **title だけ**です（順番・前提・出る条件は書けません）。
- ⚠ 所属は「**そのカードが出た瞬間、勇者が何の話として気にしているか**」で決めます
  （⚠ 後から見た結果論では決めません）。
- ⚠ まだ出ていないカードは、題名も件数も出ません。見えているカードが全部片づくと
  「いまは気になることはない」になり、★新しいカードが出ればまた開きます（⚠ 「完了」とは出しません）。
- ★`id` の頭の数字 NNN は**編集時の整理番号**です。⚠ 表示の順・依存関係・攻略の順を意味しません。
- ★`all_of: false` は書かなくて同じです（既定は「どれか 1 つ」）。⚠ `true` は止まります。
- ★`retires_all: true` で「**全部**そろって初めて片づく」になります。
- ★**複数の条件がそろったら出す**（2026-09-27 / RX3-0436）:

  ```yaml
  appears_when:
    - 聞いた: A          # ★1 本で出る
    - all_of:            # ★B と C が**両方**そろったら出る
        - 聞いた: B
        - 行った: C
    - any_of:            # ★D か E（⚠ 並べて書くのと同じ）
        - 聞いた: D
        - 聞いた: E
  ```

  ⚠ 行どうしは「どれか 1 つ」、`all_of` の中は「全部」。⚠ 入れ子・NOT・個数は書けません。
  ⚠ `all_of` の 1 本でも名前が引けなければ、その組は**丸ごと使いません**（★AND が黙って短くならない）。
- ★出る条件が 1 度も成立していないカードは、⚠ 片づく条件だけが先に成立しても**画面に出ません**。
- ★`done: <片づいたときに分かったこと>`（任意 / RX3-0437）を書くと、片づいたときに memo の代わりに
  その文が scenario の「分かったこと」に出ます。⚠ **その時点で勇者が知ったことだけ**を書きます
  （★まだ出ていないカードの話は書かない。⚠ 文章は機械では検査できません）。
- ⚠⚠ **`持った:` と `入手した:` は別の意味です**（2026-09-28 / RX3-0443）。

  ```text
  持った:     ★いま持っているか        ⚠ 使う・渡す・イベントで消えると**成立しなくなる**
                                      → ★「持っている間だけ意味がある」カードに使う
  入手した:   ★一度でも手に入れたか    ⚠ 一度成立したら**戻りません**
                                      → ★ふつうの「○○を手に入れる」カードはこちら
  ```

  ★`入手した:` の材料は、次の**全部を合わせたもの**です。

  ```text
  ① 持ち物を覗いて見えた品        ★`持った:` と同じ材料
  ② 宝箱から入手した記録
  ③ 「しらべる」で入手した記録
  ④ 入手のできごとの記録
  ```

  ⚠⚠ ② 〜 ④ が要るのは、★拾ってすぐ使った・渡した品は ① に**1 度も入らない**からです
  （⚠ 実測で 7 種が抜けていました）。
  ★2026-09-28 時点で、原本のカードは**全部 `入手した:`** を使っています。
  ⚠ ただし `持った:` は残してあります（★将来「持っている間だけ」のカードを書けるように）。
- ⚠⚠ `聞いた:` には**正規の名前**（ROM の名前 / `location-names.csv` の name / 一般の語）を書きます。
  ⚠ ゲーム内の会話の文の断片は書きません（RX3-0440）。
  ★ゲームが別の言い回しで言うときは、**Concept Alias**（`data/dq3/concept-aliases.yaml`）に登録します。
  会話にその言い回しが出たら、正規の名前を聞いたことになります（例: ひあがらせるつぼ → かわきのつぼ）。
  ⚠ 同じ言い回しを 2 つの Concept に書くと検査が ERROR にします。★検査は `python scripts/dq3_hero_memo_check.py`。
- ★`聞いた:` には一般の語（`data/dq3/concept-words.csv` / 例: オーブ）も書けます。
  ⚠ 語は人が 1 行ずつ足します（★初出の会話番号を `evidence` に）。
- ★同じ名前を何人から聞いても、勇者会議では**1 つの知識**です（★詳細に「×N 回」と出ます）。
- ★いつ見えるかは `python scripts/dq3_hero_memo_check.py --timeline` で確かめられます
  （→ `work/hero-memo-timeline-audit.md`。⚠ 会話の断片を含むので Git に入れません）。
- ★カード候補を記録から出す道具は `scripts/dq3_hero_memo_candidates.py` です
  （⚠ 旧名 `dq3_scenario_source.py`。scenario とは別の意味なので改名しました）。


⚠⚠ **この出力を Git に入れないでください。**
★原作の会話テキストがそのまま入っています（⚠ `work/` は Git 管理外なので、
そこに置いてあるかぎり安全です）。

⚠⚠ **まず 1 件だけ**書いてください。★実機で画面に出ることを確かめてから増やします
（⚠ 形が違っていると、たくさん書いた分が全部やり直しになります）。
